# 최근 변경 요약

이 문서는 최근 작업을 빠르게 파악할 수 있도록 기능별로 묶은 요약본이다.

## 1. Next.js 마이그레이션

기존 Vite + Express 구조를 Next.js 15 App Router 기반으로 정리했다.

- 루트 진입점은 `app/page.tsx`
- 공통 레이아웃은 `app/layout.tsx`
- API는 `app/api/**/route.ts` 로 이동
- 서버 분석 로직은 `src/lib/server/newsService.ts` 로 분리
- Vercel 배포는 Next.js 프레임워크로 단순화

## 2. 초기 로딩 체계

대시보드 첫 진입에서 빈 화면 대신 자동으로 데이터가 채워지도록 바꿨다.

- 최신 세션이 있으면 우선 표시
- 최신 세션이 없거나 비어 있으면 자동으로 분석 1회 실행
- 분석 실패 시 사용자에게 더 명확한 메시지를 보여줌

## 3. 최신 뉴스 페이지

기사 목록이 너무 길게 보이는 문제를 페이지네이션으로 해결했다.

- 30개 단위로 페이지 분리
- 이전 / 다음 버튼 제공
- 필터, 감성, 검색, 정렬이 바뀌면 현재 페이지를 1로 리셋
- 오늘 DB 데이터가 없으면 현재 세션 결과를 대신 표시

## 4. 로그 체계

개발 중 API 호출과 서버 이벤트를 추적하기 쉽게 정리했다.

- 서버용 공통 로거 추가
- API 요청과 실패 지점 로그 기록
- `logs/news_dash.log` 에 파일 기록
- `instrumentation.ts` 는 console-only 로 유지

## 5. 개발 서버 안정화

`npm run dev` 가 포트를 몰래 바꾸지 않도록 고정했다.

- 3000 포트 고정
- 포트 충돌 시 즉시 실패
- 브라우저와 실제 실행 서버가 다른 포트를 보는 문제 방지

## 6. 검증 결과

- `npm run lint` 통과
- `npm run build` 통과
